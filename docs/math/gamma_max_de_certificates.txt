Gamma Max-DE Certificates
=========================

Status.
-------

This is a research/theory note backing the implemented closed-form
Gamma-rate certificate core in src/velvet/research/gamma_rate.py. The
implemented branch covers positive-part moments, the shifted-q L2 upper,
deterministic one-step lower, Monte Carlo LCB, and reserve-price admission
comparison. It does not implement the finite-horizon Gauss-Laguerre dynamic
program described later in this note.

The point of this note is to record what survives when the Bernoulli payoff
bound

    0 <= (theta - v)^+ <= 1 - v

is replaced by a Gamma posterior on an unbounded positive parameter.


Setup and convention.
---------------------

Use the shape-rate Gamma parameterization

    theta | F_0 ~ Gamma(alpha,beta),

with density

    f(theta)
    =
    beta^alpha / Gamma(alpha)
        theta^(alpha-1) exp(-beta theta),

where

    alpha > 0,
    beta > 0,
    v >= 0.

Define the upward-gap payoff

    X_v = (theta - v)^+.

Let

    P(a,x) = gamma(a,x) / Gamma(a),
    Q(a,x) = 1 - P(a,x),

where P is the regularized lower incomplete gamma function and Q is the
regularized upper tail.

For actual cost or latency minimization, the natural gap is often

    X_v^- = (v - theta)^+.

That lower-tail payoff is bounded by v. The unbounded-support issue in this
note concerns the requested upward gap (theta - v)^+.


1. Closed-form expected improvement and moments.
------------------------------------------------

Set

    x = beta v.

For r >= 0,

    E[theta^r 1_{theta > v}]
    =
    beta^(-r) Gamma(alpha+r) / Gamma(alpha)
        Q(alpha+r, beta v).

Therefore

    E[theta 1_{theta > v}]
    =
    alpha / beta * Q(alpha+1, beta v),

and the Gamma expected improvement is

    m_v
    =
    E[(theta - v)^+]
    =
    alpha / beta * Q(alpha+1, beta v)
    -
    v Q(alpha, beta v).

Equivalently, with h_v(a,b) denoting the Gamma EI functional,

    h_v(a,b)
    =
    a / b * Q(a+1, b v)
    -
    v Q(a, b v).

The second raw moment of the improvement payoff is

    s_v
    =
    E[(theta - v)^+^2]
    =
    alpha(alpha+1) / beta^2 * Q(alpha+2, beta v)
    -
    2 v alpha / beta * Q(alpha+1, beta v)
    +
    v^2 Q(alpha, beta v).

Thus

    Var(X_v) = s_v - m_v^2.

For the one-sided L2 certificate, define

    q_v = E[(X_v - m_v)_+^2].

Since X_v > m_v iff theta > v + m_v,

    q_v
    =
    alpha(alpha+1) / beta^2 * Q(alpha+2, beta(v+m_v))
    -
    2 (v+m_v) alpha / beta * Q(alpha+1, beta(v+m_v))
    +
    (v+m_v)^2 Q(alpha, beta(v+m_v)).

This satisfies

    0 <= q_v <= s_v - m_v^2.

Lower-tail/minimization variant.
For

    X_v^- = (v - theta)^+,

the EI is

    E[(v - theta)^+]
    =
    v P(alpha, beta v)
    -
    alpha / beta * P(alpha+1, beta v).

In that case

    0 <= X_v^- <= v,

so a bounded-payoff constant B_v = v is available. The rest of this note
returns to the upward gap X_v = (theta - v)^+.


2. Posterior martingale and finite-horizon lower certificates.
--------------------------------------------------------------

Let (F_n) be a posterior filtration generated by hypothetical future
observations under a conjugate Gamma model, and define

    M_n = E[X_v | F_n].

Whenever the posterior after n observations is

    theta | F_n ~ Gamma(alpha_n,beta_n),

we have

    M_n = h_v(alpha_n,beta_n).

Because M_n is the posterior mean of a fixed integrable payoff X_v,

    E[M_{n+1} | F_n]
    =
    E[E[X_v | F_{n+1}] | F_n]
    =
    E[X_v | F_n]
    =
    M_n.

Thus (M_n) is a nonnegative posterior-mean martingale under the posterior
predictive law.

Define the exact Gamma Max-DE value

    Phi_v = E[sup_{n >= 0} M_n].

For every finite horizon r,

    L_v^(r)
    =
    E[max_{0 <= n <= r} M_n]

is a valid lower certificate, since

    max_{0 <= n <= r} M_n <= sup_{n >= 0} M_n

pathwise.

When repeated sampling identifies theta and M_n -> X_v almost surely, the
terminal-augmented lower certificate

    L_v,+^(r)
    =
    E[max{X_v, M_0, ..., M_r}]

is also valid and increases to Phi_v under monotone convergence.


Poisson likelihood.
-------------------

Assume unit-exposure Poisson observations

    Y_i | theta ~ Poisson(theta),

conditionally independent given theta. Then

    alpha_n = alpha + sum_{i=1}^n Y_i,
    beta_n  = beta + n,

and

    M_n
    =
    h_v(alpha + sum_{i=1}^n Y_i, beta+n).

The one-step posterior predictive law at state Gamma(a,b) is negative binomial:

    Pr(Y=y | a,b)
    =
    Gamma(a+y) / (Gamma(a) y!)
        (b/(b+1))^a
        (1/(b+1))^y,

for y = 0,1,2,....

For the non-terminal finite-horizon lower certificate, define

    G_0(a,b,z) = z,

and for k >= 0,

    G_{k+1}(a,b,z)
    =
    sum_{y=0}^infty
        Pr(Y=y | a,b)
        G_k(a+y, b+1, max{z, h_v(a+y,b+1)}).

Then

    L_v^(r)
    =
    G_r(alpha,beta,h_v(alpha,beta)).

For the terminal-augmented version, replace the terminal condition by

    G_0^+(a,b,z) = z + h_{v+z}(a,b),

and use the same recursion. Then

    L_v,+^(r)
    =
    G_r^+(alpha,beta,h_v(alpha,beta)).

In computation, truncating the infinite predictive sum without renormalizing
gives a conservative lower approximation because all terms are nonnegative.


Exponential likelihood.
-----------------------

If

    T_i | theta ~ Exponential(rate theta),

then Gamma is conjugate for the rate theta, and

    alpha_n = alpha + n,
    beta_n  = beta + sum_{i=1}^n T_i.

Thus

    M_n
    =
    h_v(alpha+n, beta + sum_{i=1}^n T_i).

The one-step posterior predictive density at state Gamma(a,b) is Lomax:

    p(t | a,b)
    =
    a b^a / (b+t)^(a+1),

for t >= 0.

The non-terminal recursion is

    G_0(a,b,z) = z,

and

    G_{k+1}(a,b,z)
    =
    int_0^infty
        a b^a / (b+t)^(a+1)
        G_k(a+1, b+t, max{z, h_v(a+1,b+t)})
    dt.

The terminal-augmented version again uses

    G_0^+(a,b,z) = z + h_{v+z}(a,b).

Important modeling note: in this exponential model, theta is the rate, not the
mean latency. If the latent quantity of interest is mean latency 1/theta, the
payoff and conjugate prior must be redefined.


3. Exponential-rate finite-horizon DP and offline compilation.
--------------------------------------------------------------

This section records a computational-certification form for the exponential-rate
model. It distinguishes:

1. The exact finite-horizon Bellman recursion.
2. A compiled numerical approximation or certified envelope for the
   finite-horizon lower certificate.
3. The analytic L2 upper certificate for the infinite-horizon value.

For this section, write

    g_v(a,b) = h_v(a,b)

for the Gamma expected-improvement functional.

Assume again

    Y_i | theta ~ Exponential(rate theta),

with posterior

    theta | F_n ~ Gamma(a_n,b_n),
    a_n = alpha+n,
    b_n = beta + sum_{i=1}^n Y_i.

For t remaining observations, define

    V_0(a,b,z) = z,

and

    V_t(a,b,z)
    =
    E[
        V_{t-1}(
            a+1,
            b+Y,
            max{z, g_v(a+1,b+Y)}
        )
    ],

where Y has predictive density

    p(y | a,b) = a b^a / (b+y)^(a+1),
    y >= 0.

Then

    L_v^(r)
    =
    V_r(alpha,beta,g_v(alpha,beta)).

The useful exact change of variables is

    x = a log(1 + y/b),
    y = b(exp(x/a) - 1),
    b+y = b exp(x/a),

so

    dy = b/a exp(x/a) dx.

Therefore

    a b^a / (b+y)^(a+1) dy = exp(-x) dx,

and the Bellman recursion becomes

    V_t(a,b,z)
    =
    int_0^infty exp(-x)
        V_{t-1}(
            a+1,
            b exp(x/a),
            max{z, g_v(a+1,b exp(x/a))}
        )
    dx.

This makes Gauss-Laguerre quadrature the natural quadrature rule:

    V_t(a,b,z)
    approximately equals
    sum_{i=1}^q w_i
        V_{t-1}(
            a+1,
            b exp(x_i/a),
            max{z, g_v(a+1,b exp(x_i/a))}
        ),

where (x_i,w_i) are Gauss-Laguerre nodes and weights for the weight exp(-x).


Shape layers.
-------------

For fixed initial alpha and finite horizon r, the shape coordinate is
deterministic:

    A_n = alpha+n.

No continuous shape dimension is needed. Use

    u = log b,

and define a layer-indexed value surface

    H_n(u,z)
    =
    value from layer n to horizon r.

The terminal condition is

    H_r(u,z) = z.

For n = 0,...,r-1, the recursion is

    H_n(u,z)
    =
    int_0^infty exp(-x)
        H_{n+1}(
            u + x/A_n,
            max{z, g_v(A_{n+1}, exp(u + x/A_n))}
        )
    dx.

Then

    L_v^(r)
    =
    H_0(log beta, g_v(alpha,beta)).

This is the form most suitable for offline compilation.


Finite-horizon saturation boundary.
-----------------------------------

For t remaining observations from state (a,b,z), the exact saturation boundary
is

    z_t^*(a,b) = g_v(a+t,b).

Indeed, after k <= t future exponential observations,

    a_k = a+k <= a+t,
    b_k = b + sum_{i=1}^k Y_i >= b.

For the upward gap, g_v(a,b) is increasing in a and decreasing in b. Hence

    g_v(a+k,b_k)
    <=
    g_v(a+k,b)
    <=
    g_v(a+t,b).

Therefore, if

    z >= g_v(a+t,b),

then no future posterior mean can exceed z, and

    V_t(a,b,z) = z.

Conversely, if

    z < g_v(a+t,b),

then with positive probability the next t exponential observations are all
arbitrarily small. The final posterior rate can be arbitrarily close to b, and
the final posterior expected improvement can approach g_v(a+t,b). Thus the
boundary is sharp.

This finite-horizon boundary does not restore a Bernoulli-style infinite-horizon
bound. As t -> infinity,

    g_v(a+t,b) ~ (a+t)/b - v,

so the deterministic finite-horizon cap grows without bound. The upward Gamma
case still has

    B_v = infinity

for the infinite-horizon problem.


Compactified value surface.
---------------------------

In layer notation, the final shape at horizon r is

    A_r = alpha+r.

At layer n, define the saturation boundary

    z_n^*(u) = g_v(A_r, exp(u)),

and the normalized running maximum coordinate

    zeta = z / z_n^*(u).

For feasible nonsaturated states,

    0 <= zeta <= 1.

Define

    W_n(u,zeta)
    =
    H_n(u, zeta z_n^*(u)) / z_n^*(u).

Then

    W_n(u,zeta) = zeta

for zeta >= 1, so the compiled domain only needs to resolve zeta in [0,1].

Under one Bellman step,

    u' = u + x/A_n,

and

    z'
    =
    max{
        zeta g_v(A_r, exp(u)),
        g_v(A_{n+1}, exp(u'))
    }.

The next normalized coordinate is

    zeta' = z' / g_v(A_r, exp(u')).

Thus

    W_n(u,zeta)
    =
    int_0^infty exp(-x)
        g_v(A_r, exp(u')) / g_v(A_r, exp(u))
        W_{n+1}(u', zeta')
    dx,

with saturation whenever zeta' >= 1.

This is a useful target for Chebyshev, spline, sparse-grid, or other surrogate
compilation.


Offline and online split.
-------------------------

Offline, one compiles approximate or certified surfaces for

    H_n(u,z)

or

    W_n(u,zeta),

for n = 0,...,r.

Gauss-Laguerre quadrature removes the need for state-dependent numerical
integration rules. The quadrature nodes and weights are fixed, and the state
transition is simply

    u -> u + x_i / (alpha+n).

Online, evaluate either

    V_r(alpha,beta,g_v(alpha,beta)),

or, in layer notation,

    H_0(log beta,g_v(alpha,beta)).

If validated lower and upper envelopes are available, then

    H_lower,0(log beta,g_v(alpha,beta))
    <=
    L_v^(r)
    <=
    H_upper,0(log beta,g_v(alpha,beta)).

For a lower certificate, the relevant chain is

    H_lower,0(log beta,g_v(alpha,beta))
    <=
    L_v^(r)
    <=
    Phi_v.

A plain spectral approximation is not automatically a certificate. To make it a
certificate, interpolation error, quadrature error, and truncation or tail error
must be bounded with the correct sign.

The compiled finite-horizon surface should not be used as the infinite-horizon
upper certificate unless its error analysis proves that claim. For the upward
Gamma gap, the robust analytic upper certificate remains moment based:

    Phi_v
    <=
    m_v + 2 sqrt(s_v - m_v^2),

with the sharper one-sided q_v certificate available when q_v is computed.

Thus the conservative computational-certification chain is

    H_lower,0(log beta,g_v(alpha,beta))
    <=
    L_v^(r)
    <=
    Phi_v
    <=
    m_v + 2 sqrt(s_v - m_v^2).

The important conceptual correction is:

    Offline spectral compilation can eliminate runtime integration only by
    precomputing a value surface, not merely by finding a boundary.

The saturation boundary is real and useful,

    z_t^*(a,b) = g_v(a+t,b),

but below that boundary the value function is genuinely two-dimensional in
(b,z), or in compactified coordinates (u,zeta).


4. Upper certificates and the unbounded-support issue.
------------------------------------------------------

For the Bernoulli payoff,

    0 <= (theta - v)^+ <= 1 - v.

This deterministic bound is used twice:

1. It gives the pathwise cap M_n <= 1-v.
2. It truncates the Ville/layer-cake integral at B_v = 1-v.

For the Gamma upward-gap payoff,

    X_v = (theta - v)^+

is unbounded, and

    ess sup X_v = infinity.

Therefore the Bernoulli bounded-payoff certificate

    m_v [1 + log(B_v / m_v)]

does not transfer with B_v = infinity. It becomes infinite and is not useful.
There is no finite bounded-payoff log-envelope upper for this Gamma-rate
upward gap, and the implementation must not expose a bounded-payoff minimum
certificate for this family.

The Gamma case is controlled by moments instead. Since Gamma has a finite
second moment, X_v is in L2. Let

    M^* = sup_{n >= 0} M_n.

For the centered martingale N_n = M_n - m_v, Doob's L2 inequality gives

    E[M^*]
    <=
    m_v + E[sup_n |N_n|]
    <=
    m_v + 2 sqrt(s_v - m_v^2).

The one-sided version is sharper. Since

    M^* = m_v + sup_n (M_n - m_v)^+,

and (M_n - m_v)^+ is a nonnegative submartingale, Doob L2 and conditional
Jensen give

    E[M^*]
    <=
    m_v + 2 sqrt(q_v).

Thus

    U_v^{Gamma,L2}
    =
    m_v + 2 sqrt(q_v)

is a valid O(1) Gamma upper certificate, with the symmetric fallback

    m_v + 2 sqrt(s_v - m_v^2)

also valid but weaker.

The verified implementation uses the shifted-q L2 certificate as the preferred
finite upper:

    Phi_v
    =
    E[M^*]
    <=
    U_v^Gamma
    :=
    m_v + 2 sqrt(q_v).

The symmetric second-moment term is retained only as a looser fallback. No
Gamma-rate upper in this branch uses a bounded-payoff log envelope or a
mean-times-log term.

For alpha > 0, beta > 0, and finite v >= 0, the upward Gamma tail is positive,
so m_v > 0. Since Gamma has finite second moment, s_v is finite and
U_v^Gamma is finite.

If only the mean m_v were known, with no boundedness or higher-moment control,
there would be no finite analogue of the Bernoulli B_v-based certificate.


5. Validation sketch.
---------------------

The following pseudocode validates the closed forms and the martingale
certificate under Poisson-conjugate updating. The exponential version replaces
the update block as shown below.

    import numpy as np
    from scipy.special import gammaincc

    rng = np.random.default_rng(12345)

    def gamma_ei(a, b, v):
        x = b * v
        return (a / b) * gammaincc(a + 1, x) - v * gammaincc(a, x)

    def gamma_second(a, b, v):
        x = b * v
        return (
            a * (a + 1) / b**2 * gammaincc(a + 2, x)
            - 2 * v * a / b * gammaincc(a + 1, x)
            + v**2 * gammaincc(a, x)
        )

    def gamma_q(a, b, v):
        m = gamma_ei(a, b, v)
        w = v + m
        x = b * w
        return max(
            a * (a + 1) / b**2 * gammaincc(a + 2, x)
            - 2 * w * a / b * gammaincc(a + 1, x)
            + w**2 * gammaincc(a, x),
            0.0,
        )

    def gamma_upper(a, b, v):
        m = gamma_ei(a, b, v)
        q = gamma_q(a, b, v)
        return m + 2.0 * np.sqrt(q)

    # Closed-form EI check:
    theta = rng.gamma(shape=a, scale=1.0 / b, size=n_paths)
    assert abs(np.maximum(theta - v, 0.0).mean() - gamma_ei(a,b,v)) < tolerance

    # Poisson posterior-martingale update:
    theta = rng.gamma(shape=a0, scale=1.0 / b0, size=n_paths)
    A = np.full(n_paths, a0)
    B = np.full(n_paths, b0)
    max_m = gamma_ei(A, B, v)
    for _ in range(n_steps):
        Y = rng.poisson(theta)
        A += Y
        B += 1.0
        max_m = np.maximum(max_m, gamma_ei(A, B, v))

    empirical_sup = np.maximum(max_m, np.maximum(theta - v, 0.0)).mean()
    assert empirical_sup <= gamma_upper(a0, b0, v) + monte_carlo_guard

For exponential-conjugate validation, replace the Poisson update block with

    T = rng.exponential(scale=1.0 / theta)
    A += 1.0
    B += T

and keep the same M_n = h_v(A,B), lower certificate, empirical supremum, and
upper certificate.


Conclusion.
-----------

Gamma upward-gap Max-DE keeps the posterior-mean martingale structure and admits
finite lower and upper certificates, but the Bernoulli bounded-support
certificate does not survive. The replacement is moment control:

    bounded Bernoulli payoff -> deterministic cap B_v,
    unbounded Gamma payoff   -> finite second moment and q_v.

This distinction must be explicit in any implementation or public claim.
