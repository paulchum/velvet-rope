Dirichlet-Categorical Upper Certificates
========================================

Let W ~ Dirichlet(gamma_1, ..., gamma_J) be the payoff-level grouped
posterior, let X = sum_j c_j W_j, and let

    Y = (X - v)^+.

For the posterior filtration F_n generated by future categorical draws, the
Max-DE upper target is

    Phi_v = E[sup_n E[Y | F_n]].

Writing M_n = E[Y | F_n], (M_n) is a bounded nonnegative martingale. With

    B_v = max_j (c_j - v)^+,
    m_v = E[Y],

we have 0 <= M_n <= B_v. Therefore the deterministic horizon-free upper
certificate remains

    U = min{
        B_v,
        m_v * (1 + log(B_v / m_v)),
        m_v + 2 * sqrt(q_or_v)
    },

with U = 0 when B_v = 0 or m_v = 0. The boundedness term is immediate. The
log term follows by integrating Ville's inequality for the nonnegative
martingale M_n. The L2 term follows by applying Doob's L2 inequality to the
centered martingale M_n - m_v.

The one-sided L2 term uses the canonical identity

    q_v = G_2(gamma, c; v + m_v),

where G_2(gamma, c; t) is the grouped positive-part second moment

    E[(X - t)_+^2].

This equals E[((Y - m_v)^+)^2] because Y = 0 when X <= v. It is sharper than
the symmetric variance route because

    q_v <= E[(Y - m_v)^2] = E[Y^2] - m_v^2.

For J = 2, the grouped Dirichlet law reduces to a Beta law on the upper payoff
weight. The two-level G_1 and G_2 formulas are the same incomplete-beta tail
formulas used by the Beta-Bernoulli runtime, so method="moment" reduces exactly
to the proven Beta-Bernoulli upper certificate.

For J <= 3, the implementation can evaluate G_2(gamma, c; v + m_v) through the
existing grouped positive-part moment helper and uses the one-sided q_v term.
For J >= 4, exact G_2 in the current code path requires recursive quadrature
over payoff levels. The scalable upper path therefore uses the deterministic
raw-moment fallback:

    m_v <= sqrt(E[(X - v)^2]),
    q_v <= min(B_v^2, E[(X - v)^2]).

This is looser than exact q_v but remains quadrature-free and conservative. If
a future implementation adds a quadrature-free exact or tighter conservative
G_2 evaluator for arbitrary J, the J >= 4 scalable path should use it before
falling back to raw moments.

Finite-Horizon Refined Upper
----------------------------

The horizon-free certificate coexists with a path-conditioned finite-horizon
upper. It is not a replacement for the O(1) cap; it is a tightening available
when paying for r steps of posterior-predictive branching.

For a posterior state a and running maximum z, define

    base(a,z) = min{
        B_v,
        z + G_1(a,c;v) * log(B_v / z),
        z + 2 * sqrt(G_2(a,c;v+z))
    },

with the log term treated as 0 when z = 0. The recursion averages this terminal
base over categorical posterior-predictive branches, updating

    z <- max(z, G_1(a_next,c;v)).

The public refined_upper_certificate(v, r) returns the monotone minimum over
depths 0..r together with the horizon-free cap. This gives a convergent
two-sided squeeze when paired with the existing finite-horizon lower
certificate, but method="moment" and refined_upper_certificate remain upper
certificates rather than exact Max-DE values.
