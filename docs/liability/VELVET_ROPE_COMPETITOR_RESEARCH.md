# Velvet Rope Competitor Research

This track researches major agent frameworks, workflow agents, MCP/action layers, observability systems, and guardrail/HITL tools against the Velvet Rope proof contract.

The question for every competitor/category:

Can this system prove, with pre-execution artifacts, that no consequential action crossed into execution without a valid warrant?

Tier 1 systems tracked in v0.1:

- OpenAI Agents SDK
- LangGraph / LangChain agents
- Microsoft Agent Framework
- AutoGen
- Semantic Kernel Agent Framework
- Google Agent Development Kit / ADK
- CrewAI
- LlamaIndex agents/workflows
- Zapier Agents / Zapier MCP
- n8n AI agents/workflows

Rows are `trace_audit_only` unless a live adapter actually runs.
