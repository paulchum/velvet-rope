# Velvet Rope Competitor Gap Theory

Tool calling without pre-execution warrant is classified as likely liability unless the system proves per-action authority before execution.

Observability without admission is observability, not safe execution.

Human approval is partial unless approval is bound to candidate action, admission decision, execution context, warrant, seal, and replay.

MCP allowlists are necessary but insufficient. They can block unlisted tools, but they do not prove that listed tool calls had budget, consent, jurisdiction, policy, and replay authority.

Final-output guardrails are insufficient for action safety unless they intercept tool/action execution before it happens.

Workflow automation without action-path trace is non-auditable for consequential action.
