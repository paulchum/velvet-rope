# Design Index

This directory contains design authorities for work that is not yet fully
implemented.

For Warrant-Bound Credentials (WBC) and Mediation Coverage Certificates (MCC),
apply design authority in this order:

1. `WBC_MCC_ADJUDICATION.md`
2. `WBC_MCC_DESIGN_v0.2.md`
3. Existing code conventions

If a work order conflicts with a higher-priority document, stop and resolve the
conflict before implementing.
