# Velvet product site

This static site extends the visual language of the public ShadowPath replay into a
buyer-facing description of Velvet's implemented product surfaces.

Preview from the repository root:

```bash
python -m http.server 4173
```

Then open `/site/` in the local preview. The page has no package-manager or build-step
dependency. Its proof replay uses the exact eight route classes from the committed
ShadowPath fixture; the portfolio panel is explicitly labelled as an illustrative UI for
the implemented portfolio schema.

Before changing product claims, review [`../docs/public/CLAIMS.md`](../docs/public/CLAIMS.md)
and [`../IMPLEMENTATION_STATUS.md`](../IMPLEMENTATION_STATUS.md).
